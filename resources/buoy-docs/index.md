# Network interface addresses

Inspect every IPv4 and IPv6 interface address, including IPv6 scope, on Linux.

Import `networkinfo` or `networkinfo.NetworkInfo`. The supported public entry points are listed in the [API contracts](api.md); platform backend modules are implementation details.
